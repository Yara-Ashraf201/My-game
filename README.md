Dragon Jungle Race
A fast-paced, browser-based endless runner game where you control a fire-breathing dragon sprinting through a dangerous jungle. Dodge rocks and spikes, rack up points, and see how long you can survive!


Gameplay

You are a dragon racing through an ever-scrolling jungle. Obstacles (rocks and spikes) approach from the right. Jump over them to survive. Hit one, and it is instant game over.
The longer you survive, the faster the game gets. Every obstacle you successfully pass increases your score multiplier (up to ×5), so skilled players can earn massive scores.
Tech Stack

Technology	   Purpose
HTML5 Canvas	 Game rendering
CSS3          	UI styling, animations, overlays
Vanilla JavaScript     	Game logic, physics, input handling
Just open the file and play.
